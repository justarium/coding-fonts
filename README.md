# coding fonts

This website is a fork of [CSS-Tricks/coding-fonts][css-tricks-coding-fonts]
with custom modifications, powered by [Eleventy](https://www.11ty.dev/).

```shell
pnpm install
pnpm run dev
# open http://localhost:8080/
```
